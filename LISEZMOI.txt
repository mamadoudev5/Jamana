JAMANA v1.2 - projet APK (fonctionne hors ligne)

  www/                       appli (index.html, data/, etc.)
  assets/                    icones
  debug.keystore             cle de signature de TEST (garde la meme signature a chaque build)
  capacitor.config.json      reglages de APK
  package.json               dependances
  .github/workflows/         compilation automatique (GitHub Actions)

Version : changez APP_VERSION en haut de .github/workflows/build-apk.yml (et VERSION dans www/index.html).
Mise a jour : remplacez les fichiers dans www/, puis git add . && git commit && git push.
GitHub recompile et publie un nouvel APK dans la section Releases.
La cle debug.keystore sert aux tests uniquement : pour le Play Store, il faudra une vraie cle secrete.
